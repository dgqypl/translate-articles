# How to keep thinking（如何保持思考）

## 元信息

- 作者：Sean Goedecke
- 原文：https://www.seangoedecke.com/how-to-keep-thinking/
- 主题：AI 时代如何保住「缓慢思考」的能力，个人随笔 / 观点文
- 篇幅：短文（约 900 词 + 3 条脚注）

## 核心观点

- **2026 年的工作像疯狂的游戏节目**：前沿模型能做队列里大部分任务时，最高效方式是把任务甩给 AI agent，在结果间不断切换上下文、快速浏览判断。不算无脑（skim 判断需要技巧），但留给缓慢仔细反思的时间少了。

- **为什么不慢下来**：① 逐字细读 LLM 输出（「咀嚼每一口 slop」）太痛苦，快速浏览挑干货反而没那么难受；② 科技行业高压，公司给了「快十倍」按钮就被激励狂按，否则被同侪比下去。

- **担忧变笨**：不是论文说的「熔化大脑」，而是心智偏向「快速浏览与判断」，远离深度思考所需的缓慢「吊床时间」（hammock time，引 Rich Hickey）。作者不全归咎 LLM，2010s 后行业本就更疯狂。

- **保持思考的方法 = 读 + 写**：
  - **写**：用自己的话写，不用 LLM 写。逼你把想法讲清楚，逼你思考。金句：脑子里的「点子」其实不是想法，只是方向感 / 碎片，**想法是在写的过程中构建出来的**。因此作者不认同「ideas are easy, execution is everything」——大多数「想法」根本还算不上想法。
  - **读真正的书**：尤其信息密度高的非虚构，是 AI slop 的对立面，读得越慢越好。类比缺钠的人渴望盐。
  - **组合**：读书 + 写读后感，是用 LLM 编程后一直渴望的过程，能感觉大脑重新舒展。

- **别丢掉习惯**：靠动脑拿工资的日子快结束了，但工作外要延续慢思考习惯。即便就工作而言：大型复杂代码库重构，当代 LLM 能做到不太出错，但**做不到有品位（tastefully）**，有时必须完全用自己的脑子把问题想透。

## 可复用的观点 / 金句

- 「想法是在写的过程中构建出来的」——反「ideas are easy, execution is everything」。
- LLM 能无错完成大型重构，但还做不到「有品位」（tastefully）——人类判断力的护城河。
- 同一任务开 6-7 个 agent 会话（探索 / 多个实现 / 多个 review / 手测）并行，而非在不同任务间切换。
