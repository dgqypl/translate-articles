## 核心观点

一篇个体创业者用 Codex 接管几乎全部业务运营的实践清单，重点不是技术而是"一个人 + 一个 agent 能顶一支团队/多个 SaaS 订阅"。

- **工作方式**：每天早上工作几小时，大部分靠对 Codex 口述，95% 的工作直接在 Codex app 里完成。
- **替代 SaaS 订阅省钱**：
  - 换掉 Collective（~$300/月）→ Codex 用定时任务打理 S-Corp 记账 + 报税，省下的钱就够覆盖 token 开销。
  - 换掉 ScoreApp（$150/月）→ 自建测评工具，生成个性化结果页 + 30 天训练计划，一个月带来 1500 条新线索。
- **零经验自建产品**：无设计/开发背景，自己重建 Stateshift app，留存上升，月入 $6k 且带来数百线索。
- **营销物料**：Codex 做了 design system、KPI 仪表盘、重建 NS Mastery 主页（替 Webflow，申请页 CTR 上升）、Thrivecart 结账页；梳理社群学员帖子做出 outcomes 成果页（手工要几百小时）。
- **内容生产**：在 Google Docs 里给长文出编辑意见（最后 15% 仍请人类编辑）；替代 $200/期的播客视频剪辑（3 机位、同步 2 小时音频、传 YouTube 带 show notes + 时间戳）；搭 Instagram 轮播图引擎（抓 80+ YouTube 文字稿 → 生成两个月轮播图 + 文案 → 接 ManyChat → 人工审核后排期发布）。
- **AI 的边界**：仍自己回邮件、手写所有对外文案，"AI 写作还没到那个火候"。
- **总结情绪**：难以想象前 AGI 时代的生活，现在是怀揣大梦想的小企业主最好的时代。
- 文末推广自己下周的免费工作坊（用 AI 时如何 stay regulated 情绪稳定）。

## 备注

这是一篇偏"个人体验安利"的短文，不是工程方法论。价值在于展示 agentic coding 工具（Codex）在真实单人业务场景里的杠杆效应：一个人用一个 agent 替换掉多个付费 SaaS + 外包 freelancer。
